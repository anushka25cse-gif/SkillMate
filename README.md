# SkillMate 🎓

> Find the skills you need. Meet the people who have them.

SkillMate is a student-focused platform designed to help students discover peers with complementary skills, find teammates for projects, collaborate on ideas, and exchange knowledge.

The platform connects students based on what they know and what they want to learn, making it easier to find the right people for the right projects.

---

## ✨ Features

### 🔐 Student Login

A simple and user-friendly login interface for students to access the SkillMate platform.

### 🏠 Dashboard

A personalized dashboard where students can view:

- Skill matches
- Project invitations
- Match accuracy
- Recommended teammates
- Recommended projects
- Recent activity
- Current skills

### 🔎 Discover

Students can discover potential teammates based on their skills, interests, and learning goals.

- Discover students
- View student skills
- Find complementary skills
- View match percentages
- Find potential teammates

### 👥 Projects & Team Formation

Students can explore projects and find suitable teammates based on the skills required.

- Browse projects
- View project requirements
- Find recommended teammates
- Invite students to projects
- Build project teams

### 🔄 Skill Swap

SkillMate enables students to exchange knowledge with each other.

**I CAN TEACH**  
Skills that a student can teach others.

**I WANT TO LEARN**  
Skills that a student wants to develop.

This helps students find peers with compatible teaching and learning goals.

## 🎨 UI/UX Design

The SkillMate interface was designed and prototyped using **Figma** before being developed using HTML and CSS.

The design focuses on:

- Clean and intuitive navigation
- Student-friendly layouts
- Card-based interfaces
- Skill tags
- Match indicators
- Clear calls to action
- Consistent visual design
- Simple user flows
